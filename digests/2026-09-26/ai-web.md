### 2.2 Project Swap: What happens when agents trade for us?  
- **发布日期 / 更新日期**：2026-09-24 / 2026-09-25 抓取  
- **分类**：research  
- **原文链接**：https://www.anthropic.com/research/project-swap  

Project Swap 是 Anthropic 继 **Project Deal** 之后，对 AI agents 在市场环境中代表人类行动的进一步实验。实验设计为一个小型图书交换市场：Anthropic 员工带来想交换的书，与 Claude 进行短暂沟通后，由 Claude 驱动的 agent 进入开放交易场景，与其他人的 agent 进行推销、讨价还价和达成交易，目标是让参与者最终拿到自己喜欢的暑期读物。

节选中给出了几个关键结果：  
- 仅通过约五分钟对话，agent 对 10 本书的排序与用户本人排序在 **61% 的成对比较上匹配**；  
- agent 在交易环节整体表现较好；  
- 市场表现不佳的主要原因不是 agent 不会交易，而是 **agent 对参与者偏好的信息不足**；  
- 在反复重跑交易市场并更换模型与指令后，Anthropic 发现 **模型本身对谈判结果的影响大于指令差异**；  
- 更强模型驱动的市场效率更高。

这篇内容的核心价值在于，它把 agent 研究从单体任务执行推进到 **多 agent 互动、偏好代表、市场效率、谈判机制和信息不对称**等更现实的问题上。相比单纯展示“AI 能帮用户买东西 / 安排行程 / 处理邮件”，Project Swap 更关注当多个 agent 同时代表不同用户利益时，系统层面的市场行为会如何变化。

从产品化角度看，Project Swap 暗示 Anthropic 正在研究未来 agent 生态中的几个关键难题：  
1. agent 如何准确理解并代表用户偏好；  
2. 多个 agent 在开放环境中交互时是否会产生有效分配；  
3. 模型能力、系统提示词、偏好采集机制分别对结果有多大影响；  
4. 当 agent 参与经济活动时，哪些失败来自模型推理，哪些来自信息结构。  

这对企业级 AI agent、自动采购、销售协商、个人数字代理以及未来的 AI-to-AI 交易系统都有直接参考意义。
